# Map hover

CircleMarkers overlap; hover often hits the wrong pin or nothing. Tooltip is fine if the pointer can actually select a site.

## Behavior

`dashboard/src/MapPanel.tsx` only (plus tooltip CSS if needed).

- Larger hit target: `radius={9}` (visual can stay ~7 via a second path, or just use 9 — prefer one circle radius 8–9).
- `eventHandlers`: `mouseover` → `e.target.bringToFront()`; `mouseout` optional reset.
- Tooltip: `sticky`, `direction="top"`. Keep the existing unit rows (kW, SOC, reachable, cmd W).
- `bubblingMouseEvents={false}` so a top pin does not immediately lose to one under it.

Do not change colors, legend, or fleet placement.
