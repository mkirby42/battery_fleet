## Learned
- Same chrome as PLAY is enough to lie about what a control does. If it sits on the timeline, draw it on the timeline.
- Wholesale nets across houses. Customer bills do not. The first 1.5 kW of discharge covers the load and loses the 14¢. The rest is export and does not.
- An offline battery keeps its last command. If it goes offline while charging, a later discharge target can be partly cancelled by that stale charge. Target miss and command tracking are different measurements.
